# Strategy card: <name>

One page that travels with the strategy. Update it at every evidence-stage change.

| Field | Entry |
|---|---|
| One line | What it does, for whom, at what horizon |
| Source of edge | Speed, accuracy, access or warehoused variance; the ledger row that carries it |
| Payer | Who pays and why they accept it |
| Mechanism | Input → expected market consequence → action → net payoff → falsifier |
| Rules | As-of inputs; entry, exit and no-trade logic; sizing; timing authority |
| Execution net | Measured costs at intended size: touch, impact, adverse drift, delay, financing |
| Capacity | Net value against size; where it stops |
| Bad state | When it loses, how much, and what else in the book loses then |
| Evidence | Verdict, evidence stage, n, eras, trials searched, deflated statistics |
| Decisive test | The next test that would change the decision |
| Kill rule | The result that retires it |
| Monitors | Mechanism signals beside P&L: lead time, markouts, premium against risk, crowding, era drift |
| Status | GREEN, PARTIAL, BLOCKED or UNVERIFIED for the latest change, with the missing proof |
